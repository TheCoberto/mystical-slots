# slot-machine

**Slot Machine** is a Minecraft Bedrock add-on. It started as a copy of the Rocket Launcher (fat-man) repo.

## Building

Use `package.ps1` from [bedrock-tools](https://github.com/TheCoberto/bedrock-tools), cloned next to this repo:

```powershell
powershell -ExecutionPolicy Bypass -File ..edrock-tools\package.ps1
```
